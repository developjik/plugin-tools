Use this command to validate a rendered plugin directory.

Run the validator, show the six stages as PASS, FAIL, or SKIP, and finish with a localized result line. Do not auto-fix. Explain SKIP as environment-dependent when the Claude or Codex CLI cannot certify runtime loading.
